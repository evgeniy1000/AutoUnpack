РАСПАКОВЩИК АРХИВОВ (AutoUnpack)
================================

Двойной клик по архиву распаковывает его в папку с тем же именем рядом
с архивом. Вопросов не задаётся, сторонние программы не нужны: работает
встроенный распаковщик Windows.


ПЕРВЫЙ ЗАПУСК
-------------
Windows разрешает назначать программу по умолчанию только вручную.
Сделать это нужно один раз:
- в последнем окне установщика отметьте «Назначить распаковщиком архивов
  по умолчанию», откроются Параметры Windows; или
- ПКМ по архиву -> Открыть с помощью -> Выбрать другое приложение ->
  «Распаковщик (в папку рядом)» -> Всегда.
Повторите для .rar и .7z, если они у вас встречаются.


КАК ПОЛЬЗОВАТЬСЯ
----------------
- Двойной клик по архиву: распаковка в папку «Имя архива» рядом с ним.
  После распаковки папка открывается поверх всех окон.
- Shift + двойной клик: архив открывается стандартным просмотром Windows,
  без распаковки.
- ПКМ -> «Распаковать в папку рядом» работает сразу, даже без назначения
  по умолчанию. В Windows 11 пункт находится в «Показать дополнительные
  параметры».

Если папка с таким именем уже есть и не пуста, архив распакуется
в «Имя (2)», «Имя (3)» и так далее, файлы не смешиваются.
Если внутри архива одна папка с тем же именем, лишняя вложенность
убирается.
На больших архивах появляется стандартное окно копирования Windows
с прогрессом и кнопкой «Отмена». При отмене недораспакованная папка
удаляется.


ЗНАЧОК В ТРЕЕ
-------------
Правый клик по значку возле часов открывает меню:
- Уведомлять о распаковке            (по умолчанию выключено)
- Открывать папку после распаковки   (по умолчанию включено)
- Запускать вместе с Windows         (по умолчанию включено)
- Выход
Об ошибках программа сообщает всегда, даже если уведомления выключены.


ФОРМАТЫ
-------
.zip — Windows 10 и 11.
.rar, .7z — Windows 11, в Windows 10 зависит от сборки.
.tar, .tar.gz, .tgz, .bz2, .xz, .zst — через встроенный tar.exe,
без окна прогресса.


УДАЛЕНИЕ
--------
Параметры -> Приложения -> «Распаковщик архивов (AutoUnpack)» -> Удалить.
