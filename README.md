# Распаковщик архивов (AutoUnpack)

Двойной клик по архиву распаковывает его в папку с тем же именем рядом с архивом. Вопросов нет, сторонние архиваторы не нужны: работает встроенный распаковщик Windows.

## Возможности

- **Двойной клик** распаковывает `Фото.zip` в папку `Фото\`, после чего папка открывается поверх всех окон.
- **Shift + двойной клик** открывает архив стандартным просмотром Windows, без распаковки.
- **Стандартное окно копирования Windows** с прогрессом и кнопкой «Отмена» появляется на больших архивах.
- **Значки архивов** совпадают с системными значками ZIP-папок Windows.
- **Значок в трее** даёт меню с уведомлениями, открытием папки после распаковки и автозапуском. Об ошибках программа сообщает всегда.
- Файлы не перезаписываются: если папка уже занята, архив распакуется в `Имя (2)`.
- Лишняя вложенность убирается: вместо `Фото\Фото\…` получится `Фото\…`.
- Пометка «скачано из интернета» сохраняется на извлечённых файлах, так что SmartScreen и защищённый просмотр Office продолжают работать.

## Установка

1. Скачайте `AutoUnpack-Setup-<версия>.exe` со страницы [Releases](../../releases/latest) и запустите.
2. В последнем окне установщика отметьте «Назначить распаковщиком архивов по умолчанию». Это откроет Параметры Windows. Можно сделать и иначе: ПКМ по архиву → «Открыть с помощью» → «Распаковщик (в папку рядом)» → «Всегда».

Программа ставится в `Program Files`, появляется в меню «Пуск» и удаляется штатно через «Параметры → Приложения».

## Форматы

| Формат | Чем распаковывается |
|---|---|
| `.zip` | Проводник Windows, с окном прогресса |
| `.rar`, `.7z` | Проводник Windows 11; в Windows 10 через `tar.exe`, если сборка его поддерживает |
| `.tar`, `.tar.gz`, `.tgz`, `.bz2`, `.xz`, `.zst` | встроенный `tar.exe` |

Требования: Windows 10 или 11, .NET Framework 4.6.2 и новее (встроен в Windows).

## Сборка из исходников

Нужен Inno Setup 6.3+ (`winget install JRSoftware.InnoSetup`).

```powershell
.\build.ps1 -Version 1.0.0
```

Результат появится в `dist\`: `AutoUnpack.exe` и `AutoUnpack-Setup-1.0.0.exe`.

GitHub Actions собирает проект при каждом пуше. Номер версии хранится в файле `VERSION`: когда в `main` появляется новая версия, готовый установщик и контрольные суммы SHA-256 автоматически публикуются в Releases.
